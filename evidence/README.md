# Testing Evidence

This folder contains selected screenshots supporting the TodoMVC testing documentation.

Screenshots are included only where they provide useful additional context for documented test results and observations.

## Responsive Testing – 375 × 667

[View responsive testing screenshot](responsive-375x667.png)

The application was tested using Chrome DevTools at a responsive viewport of **375 × 667**.

The screenshot demonstrates that:

- the TodoMVC interface remains usable at the tested viewport;
- todo items remain inside the layout;
- filters and remaining-item counter remain visible;
- no horizontal overflow was observed during this test.

## Accessibility Inspection

[View accessibility inspection screenshot](devtools-checkbox-accessibility.png)

Chrome DevTools was used to inspect the accessibility properties of a TodoMVC checkbox.

The inspected control exposed accessibility information including:

- accessible name;
- `checkbox` role;
- focusable state;
- checked state.

This screenshot supports the accessibility checks documented in the exploratory testing report and session log.
