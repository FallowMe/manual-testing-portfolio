# Manual Testing Portfolio

This repository contains selected manual software testing work completed during my Software Testing studies at TECHIN and practical QA training.

The purpose of this portfolio is to demonstrate my approach to manual testing, defect reporting, responsive and UI testing, exploratory testing, accessibility checks and team-based QA workflows.

## Projects

### 1. MyTeam Web Application – Team Testing Project

Team-based web application project completed during my Software Testing studies at TECHIN.

My main role in the project was **Software Tester / QA**.

Testing activities included:

- UI and responsive testing
- Functional testing
- Figma/design comparison
- Desktop, tablet and mobile testing
- Git branch testing
- Jira defect reporting
- Retesting after fixes
- Regression checks
- Communication with developers

During the project I created **6 Jira bug reports** for confirmed issues and also communicated smaller visual inconsistencies directly with developers.
